# Проект 1: Платформа управления учебным процессом (LMS + AI-ассистент)

Проект, выполненный в роли **Product Owner и системного аналитика**. 
Результат — рабочее веб-приложение для автоматизации учебного процесса в СПО, включающее автопроверку тестов и рекомендательную проверку работ с помощью нейросети GigaChat.


## Проблема и ценность продукта
Существующие LMS (Moodle, Google Classroom, Canvas) не закрывают специфику СПО: нет автоматической проверки тестов с тремя типами вопросов, нет рекомендательной проверки текстов нейросетью, а журнал успеваемости не адаптирован под современные реалии. Преподаватели тратят часы на рутину.

**Моё решение** снижает временные затраты преподавателей на проверку работ и даёт студентам оперативную обратную связь.

## Моя роль в проекте
В рамках учебного проекта я выступал в роли **«аналитик + product-owner»**:
- Сформулировал идею, ценность и цели продукта;
- Провёл анализ предметной области и конкурентов (Moodle, Google Classroom, Canvas);
- Собрал и описал функциональные требования (20+ функций);
- Спроектировал архитектуру системы и модель данных (10 таблиц);
- Построил диаграммы (Use Case, Activity, Sequence, ER) в draw.io;
- Написал техническую документацию и провёл тестирование.

## Стек технологий
* **Backend:** Python, Django
* **Database:** SQLite (Django ORM)
* **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
* **AI-интеграция:** GigaChat API (Sber)
* **Инструменты аналитика:** draw.io, Excel

## Ключевой функционал (Highlights)
* **Ролевая модель:** Администратор, Преподаватель, Студент.
* **Управление заданиями:** создание, редактирование, назначение на группы, дедлайны.
* **Автопроверка тестов:** 3 типа вопросов (одиночный/множественный выбор, числовой ответ) с частичным начислением баллов.
* **AI-ассистент (GigaChat):** рекомендательная проверка текстовых ответов и файлов (PDF, DOCX, TXT) с формированием оценки и комментария (human-in-the-loop).
* **Электронный журнал:** фильтрация по курсу, цветовое выделение, отметки о просрочке.
* **Массовый импорт:** загрузка групп и пользователей из Excel.
