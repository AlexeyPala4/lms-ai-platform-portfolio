# Спецификация интеграции с AI-ассистентом (GigaChat API)

В системе реализована интеграция с большой языковой моделью GigaChat (Sber) для рекомендательной проверки текстовых ответов и загруженных файлов студентов.

## 1. Назначение интеграции
Модуль AI-ассистента позволяет преподавателю получать предварительную оценку и текстовый комментарий по работе студента. Это ускоряет процесс проверки, но не заменяет преподавателя.

## 2. Сценарий взаимодействия (Sequence)
1. Преподаватель открывает карточку проверки работы студента.
2. Нажимает кнопку «Проверить нейросетью сейчас».
3. Система формирует промпт на основе задания и ответа студента.
4. Отправляет POST-запрос к GigaChat API.
5. Получает ответ, парсит оценку и комментарий.
6. Отображает рекомендацию в интерфейсе преподавателя.

## 3. Спецификация запроса (Request)

**Метод:** `POST`  
**URL:** <Эндпоинт GigaChat API (указан в официальной документации)>  
**Заголовки:**
* `Content-Type: application/json`
* `Authorization: Bearer <access_token>`

**Тело запроса (JSON):**
```json
{
  "model": "GigaChat",
  "messages": [
    {
      "role": "system",
      "content": "Ты помощник преподавателя. Отвечай кратко и по делу."
    },
    {
      "role": "user",
      "content": "Проанализируй работу студента. ЗАДАНИЕ: {task_title}. ОТВЕТ СТУДЕНТА: {student_answer}. ФОРМАТ ОТВЕТА: ОЦЕНКА: число от 2 до 5; Что хорошо: ...; Что исправить: ...; Рекомендация: ..."
    }
  ],
  "temperature": 0.3,
  "max_tokens": 100
}
