# Тест-кейсы (Функциональное тестирование)

**Метод тестирования:** «Чёрный ящик» (Black-box testing) — проверка соответствия фактического поведения системы ожидаемому.

**Общее количество тест-кейсов:** 10
**Охваченные модули:** Аутентификация, Загрузка данных из Excel, Создание заданий, Сдача работ, Проверка преподавателем, Автоматическая проверка тестов.

---

### ТК-01: Успешный вход преподавателя
* **Приоритет:** Высокий
* **Модуль:** Аутентификация
* **Предусловие:** Преподаватель с логином «Бирюкова Валерия Ивановна» и паролем «426b» существует в БД.
* **Шаги:**
  1. Ввести логин «Бирюкова Валерия Ивановна».
  2. Ввести пароль «426b».
  3. Нажать кнопку «Войти».
* **Ожидаемый результат:** Открывается личный кабинет преподавателя.
* **Статус:** Пройден

### ТК-03: Вход с неверными учетными данными

* **Предусловие:** Пользователя с логином «wronguser» не существует в БД.

### ТК-04: Загрузка групп из Excel
* **Приоритет:** Высокий
* **Модуль:** Загрузка данных
* **Предусловие:** Подготовлен файл «groups.xlsx» с колонками: Группа, Курс, Факультет.
* **Шаги:**
  1. Нажать «Загрузка групп».
  2. Выбрать файл «groups.xlsx».
  3. Нажать кнопку «Загрузить».
* **Ожидаемый результат:** В БД появляются группы «ЭК-101» и «ГЕО-401».
* **Статус:** Пройден

### ТК-05: Загрузка пользователей из Excel

* **Предусловие:** Подготовлен файл «users.xlsx» с колонками: Логин, Роль, Группа, Имя, Фамилия, Кафедра, Предметы.

### ТК-06: Создание тестового задания с вопросами
* **Приоритет:** Высокий
* **Модуль:** Задания
* **Предусловие:** Преподаватель авторизован, существует группа «ИТ-202».
* **Шаги:**
  1. Нажать «Создать задание».
  2. Заполнить поля и выбрать тип проверки «Тест».
  3. Указать количество попыток «2».
  4. Добавить вопрос «Сколько будет 2+2?» (Тип: Числовой ответ, Правильный ответ: 4, Баллы: 10).
* **Ожидаемый результат:** Задание «Тест» создано, вопрос добавлен.
* **Статус:** Пройден

### ТК-07: Прохождение теста студентом
* **Приоритет:** Высокий
* **Модуль:** Сдача работ
* **Предусловие:** Студент авторизован, существует тест «Тест» с вопросом «Сколько будет 2+2?».
* **Шаги:**
  1. Нажать «Пройти тест» у задания «Тест».
  2. Ввести ответ «4».
  3. Нажать «Отправить тест».
* **Ожидаемый результат:** Отображается страница с результатами: набранные баллы 10 из 10, оценка «5».
* **Статус:** Пройден

### ТК-08: Отправка ответа на ручную проверку
* **Приоритет:** Высокий
* **Модуль:** Сдача работ
* **Предусловие:** Студент авторизован, существует задание «Лабораторная работа №1».
* **Шаги:**
  1. Нажать «Выполнить задание».
  2. Ввести текстовый ответ.
  3. Нажать «Отправить на проверку».
* **Ожидаемый результат:** Работа появляется в разделе «Выполненные задания» со статусом «На проверке».
* **Статус:** Пройден

### ТК-09: Выставление оценки за ручную работу (с нейросетью)
* **Приоритет:** Высокий
* **Модуль:** Проверка работ
* **Предусловие:** Преподаватель авторизован, существует ответ студента на задание. Включена нейросетевая проверка.
* **Шаги:**
  1. Нажать на задание.
  2. Нажать «Проверить» у ответа студента.
  3. Нажать «Проверить нейросетью сейчас».
  4. Дождаться ответа нейросети.
  5. Выставить оценку «5» и ввести комментарий.
  6. Нажать «Сохранить проверку».
* **Ожидаемый результат:** Статус работы меняется на «Проверено». Отображается рекомендация нейросети.
* **Статус:** Пройден

### ТК-10: Автоматическое выставление «2» за просрочку
* **Приоритет:** Высокий
* **Модуль:** Автоматическая проверка
* **Предусловие:** Существует задание с дедлайном в прошлом. Студент не сдал работу.
* **Шаги:**
  1. Нажать «Журнал оценок».
  2. Найти студента в таблице.
* **Ожидаемый результат:** В ячейке отображается оценка «2» с пометкой «Просрочено».
* **Статус:** Пройден
