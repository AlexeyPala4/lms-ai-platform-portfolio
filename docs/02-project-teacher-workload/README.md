# Проект 2: Информационная система учета учебной нагрузки преподавателей

Учебный проект (Курсовой проект), выполненный в роли **системного аналитика**. 
Система предназначена для автоматизации планирования занятий, контроля нагрузки и формирования отчетности в образовательном учреждении.

## Проблема и ценность продукта
Традиционные методы учета с использованием электронных таблиц не обеспечивают надежности, не позволяют автоматически проверять ограничения (максимальная нагрузка 22 часа в неделю) и не предоставляют удобных инструментов для анализа.

**Решение:** Веб-приложение, которое автоматически контролирует недельную нагрузку, запрещает конфликты в расписании (две пары в одно время, занятия в воскресенье или в прошлом) и формирует отчеты в Excel.

## Моя роль в проекте
- Провел интервьюирование стейкхолдеров (сотрудники учебного отдела, преподаватели, финансовый отдел) для выявления требований.
- Сформулировал функциональные и нефункциональные требования (НФТ: загрузка страниц до 2 сек).
- Спроектировал базу данных на трех уровнях: концептуальном, логическом и физическом.
- Построил BPMN и UML-диаграммы (Use Case, Activity) для процессов создания расписания и управления преподавателями.
- Описал бизнес-правила (валидация 22-часового лимита, проверка конфликтов времени).
- Составил тест-кейсы, включая негативные сценарии.

## Стек технологий и инструменты
* **Backend:** Python, Django
* **Database:** SQLite
* **Frontend:** HTML, CSS, Bootstrap
* **Инструменты аналитика:** draw.io (BPMN, UML), Excel

## Ключевой функционал
* **Ролевая модель:** Администратор, Сотрудник учебного отдела, Преподаватель.
* **Управление расписанием:** добавление, редактирование и удаление занятий с проверкой конфликтов.
* **Автоматический контроль нагрузки:** система не позволяет распределить преподавателю более 22 академических часов в неделю.
* **Аналитика и отчеты:** дашборд со статистикой и детальным отчетом по дням недели.
* **Экспорт данных:** выгрузка расписания и отчетов в формат XLSX.
