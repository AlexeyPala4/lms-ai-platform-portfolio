# Тест-кейсы (Функциональное тестирование)

В процессе разработки информационной системы было проведено функциональное тестирование для проверки соответствия реализованного функционала требованиям технического задания. Тестирование охватило ключевые сценарии работы системы.

---

### ТК-01: Вход начальника учебного отдела с валидными данными
* **Приоритет:** Высокий
* **Модуль:** Аутентификация
* **Предусловие:** Пользователь зарегистрирован в системе.
* **Шаги:**
  1. Ввести логин: head_dept.
  2. Ввести пароль: head123.
  3. Нажать кнопку «Войти».
* **Ожидаемый результат:** Открывается главная страница с меню управления нагрузкой.
* **Статус:** Passed
