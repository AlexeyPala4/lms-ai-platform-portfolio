# Требования и бизнес-правила

В данном разделе собраны бизнес-цели, метрики успеха, бизнес-правила и пользовательские истории с критериями приемки.

## Бизнес-цель и KPI
**Цель:** Снизить количество мошеннических операций со стороны сотрудников B2B-клиентов на 30% за счет внедрения инструментов мгновенного контроля и блокировки.

**Метрики успеха (KPI):**
1. **Скорость блокировки:** Время от команды «Заблокировать» до применения ограничений в системе проведения платежей - не более 2 секунд.
2. **Скорость проверки лимита:** Время проверки транзакции на соответствие лимитам - не более 500 мс.
3. **Снижение инцидентов:** Снижение количества несанкционированных списаний на 30% (замер за 3 месяца после внедрения).
4. **Снижение нагрузки на поддержку:** Уменьшение количества обращений в поддержку банка по вопросам блокировки карт на 20%.
5. **Удобство использования (UX):** Доля пользователей, которые успешно настраивают лимиты с первой попытки без обращения в поддержку, должна составлять не менее 90%.

## Бизнес-правила
1. **Иерархия лимитов:** Итоговый лимит для карты = минимальное значение из всех лимитов (Банк -> Компания -> Сотрудник).
2. **Мультивалютность:** При оплате в иностранной валюте сумма конвертируется по внутреннему курсу банка на момент проверки.
3. **Временные ограничения:** Лимит может действовать только в определенное время (например, по будням с 9:00 до 18:00). В нерабочее время траты блокируются.
4. **Maker-Checker:** Изменение лимита применяется мгновенно, но требует подтверждения второго сотрудника. До подтверждения изменение имеет статус «На проверке». При отклонении лимит откатывается к предыдущему значению.
5. **Обработка транзакций:** При превышении лимита возвращается ошибка `LIMIT_EXCEEDED`, при блокировке - `CARD_BLOCKED`, вне расписания - `OUT_OF_WORKING_HOURS`.

## User Stories

**US-1: Настройка лимита для сотрудника**
*Как Финансовый директор, я хочу установить дневной лимит для конкретного сотрудника, чтобы контролировать его расходы.*
* **Критерии приемки (AC):**
  * Поля «Сотрудник», «Сумма лимита» и «Период» обязательны для заполнения.
  * Сумма лимита не может быть отрицательной или равной нулю.
  * Сумма лимита не может превышать общий лимит компании.
  * После сохранения лимит применяется к карте сотрудника мгновенно.
  * В интерфейсе отображается статус «На проверке».

**US-2: Подтверждение изменений (Maker-Checker)**
*Как Главный бухгалтер, я хочу подтверждать или отклонять изменения лимитов, чтобы исключить ошибки или мошенничество.*
* **Критерии приемки (AC):**
  * В личном кабинете есть раздел «Заявки на подтверждение».
  * В заявке отображается: кто изменил, для кого, старое и новое значение лимита.
  * При нажатии «Подтвердить» статус меняется на «Подтверждено».
  * При нажатии «Отклонить» система откатывает лимит к предыдущему значению.

**US-3: Мгновенная блокировка карты**
*Как Финансовый директор, я хочу мгновенно заблокировать карту сотрудника, чтобы предотвратить траты при потере карты.*
* **Критерии приемки (AC):**
  * Кнопка «Заблокировать» доступна в карточке сотрудника.
  * После подтверждения статус карты меняется на «Заблокирована», новые транзакции отклоняются с кодом `CARD_BLOCKED`.
  * Блокировка вступает в силу не более чем за 2 секунды.
  * Запрос на подтверждение Главбуху не требуется для экстренной блокировки.

**US-4: Прозрачность отклонения платежа**
*Как Сотрудник, я хочу получать понятную причину отказа в платеже, чтобы понимать, что мне делать дальше.*
* **Критерии приемки (AC):**
  * При превышении лимита сотрудник видит сообщение: «Превышен дневной лимит. Обратитесь к финансовому директору».
  * При блокировке: «Карта заблокирована. Свяжитесь с бухгалтерией».
  * Вне расписания: «Операции в нерабочее время запрещены».

**US-5: Уведомление о достижении порога лимита**
*Как Финансовый директор, я хочу получать уведомление, когда сотрудник потратил 90% своего лимита.*
* **Критерии приемки (AC):**
  * При достижении 90% от суммы лимита система отправляет уведомление инициатору.
  * Уведомление содержит: имя сотрудника, потраченную сумму, остаток лимита.
  * Уведомление отправляется один раз в день.

**US-6: История трат по сотруднику**
*Как Финансовый директор, я хочу видеть историю всех транзакций по карте сотрудника, чтобы проверять, на что уходят деньги.*
* **Критерии приемки (AC):**
  * В карточке сотрудника есть вкладка «История операций».
  * Отображаются: дата, сумма, продавец, статус (успешно/отклонено), причина отклонения.
  * Есть фильтр по дате (за день/неделю/месяц).
  * Суммы отображаются в валюте операции и в базовой валюте (RUB).
