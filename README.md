# Портфолио системного аналитика

Начинающий системный аналитик с техническим образованием. Имею практический опыт проектирования информационных систем: от анализа предметной области и написания User Stories до создания диаграмм (BPMN, Use Case, ER) и проведения функционального тестирования.

В данном репозитории собраны два учебных проекта, демонстрирующие полный цикл работы над IT-продуктом.

## Проекты

### Проект 1: Платформа управления учебным процессом (LMS + AI-ассистент)
Разработка системы для автоматизации учебного процесса с автоматической проверкой тестов и интеграцией с нейросетью GigaChat для рекомендательной проверки работ.
* **Роль:** Product Owner / System Analyst
* **Ключевые артефакты:** User Stories, спецификация REST API, BPMN/Use Case/Sequence/ER диаграммы, тест-кейсы.
* [Перейти к описанию проекта](./docs/01-project-lms-ai/README.md)

### Проект 2: Информационная система учета учебной нагрузки преподавателей
Разработка системы для автоматизации планирования занятий, контроля нагрузки (лимит 22 часа) и формирования отчетности.
* **Роль:** Системный аналитик
* **Ключевые артефакты:** Требования и бизнес-правила, BPMN-диаграммы, трехмерная модель БД, тест-кейсы.
* [Перейти к описанию проекта](./docs/02-project-teacher-workload/README.md)
